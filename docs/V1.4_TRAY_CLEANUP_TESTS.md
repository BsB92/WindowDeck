# WindowDeck 1.4.0 — tray icon cleanup acceptance tests

These tests apply to branch `fix/v1.4-tray-history`. **Requires local Windows 11 testing.**
They do not test Presentation Mode or the separate refresh/topmost PR.

## Settings user interface
- [ ] Open Settings in both English and Polish. Find **Maintenance / Konserwacja** near the bottom and its one-click action.
- [ ] Confirm the action remains available in System, Light and Dark theme and does not interfere with normal settings Save/Cancel.
- [ ] Confirm a portable, published single-file WindowDeck.exe exposes the same action (no external script required).
- [ ] If there are no recognized history entries from other locations, the button reports no old entries and leaves the registry unchanged.

## Preview and protection
- [ ] Run an EXE from one permanent folder and create some history by running an older build from another folder. Open cleanup from the permanent EXE.
- [ ] The preview lists each old WindowDeck.exe executable path and correct total count.
- [ ] A record pointing to the *current* WindowDeck.exe is excluded (including same-path duplicate records, which cannot be distinguished safely).
- [ ] Entries pointing to other executables, and entries without a trustworthy absolute WindowDeck.exe path, are excluded.
- [ ] Cancel leaves registry entries and settings unchanged.

## Backup and cleanup
- [ ] Confirm Remove: each selected record has a distinct .reg export in `%LocalAppData%\WindowDeck\TrayIconBackups\<timestamp>`.
- [ ] Confirm backups exist **before** removal; if backup fails, no entries are deleted.
- [ ] Confirm the active icon and other applications' personalization preferences are preserved.
- [ ] Confirm the success message includes the number removed and exact backup folder.
- [ ] Close/reopen Windows Taskbar Settings; if old entries remain, sign out/in and verify again.
- [ ] Optional: restore one saved .reg with `reg import` and verify the record is restored; avoid leaving test garbage.

## Regression and limits
- [ ] A Visual Studio debug run still may create another Windows history entry; treat it separately from multiple **live** icons in the tray.
- [ ] No changes to autostart, tray menu, global hotkey, or window switching.
- [ ] The feature is never run automatically during app startup or updating.

Do not merge or publish until accepted on Windows 11.
