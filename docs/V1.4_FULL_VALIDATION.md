# WindowDeck 1.4.0 — integrated local Windows 11 acceptance

Branch: feature/v1.4-integrated-window-sets. It contains the work from PR #42, #45, #47 and the Saved sets feature. PRs are still unmerged.
**Required**: Build and test on Windows 11; GitHub connector access cannot compile or run the application.

## Critical startup crash regression — Saved Sets (Parameter is not valid)

- [ ] Launch WindowDeck on Windows 11, then immediately click **Saved Sets**. No unhandled exception, "Parameter is not valid", app exit, or error dialog should occur.
- [ ] Repeat with **zero saved sets**, **one saved set**, and **a set containing many documents and long paths**. Select different sets repeatedly and reopen the manager multiple times.
- [ ] Check both Polish/English UI, light/dark themes and 100%, 125%, 150% DPI scaling.
- [ ] Saved sets opens without exceptions and displays a **borderless application-group preview** with no ListView, GDI+ bitmap spacer, white header row, or dense gridlines.
- [ ] Test after restarting WindowDeck, rather than just rerunning the existing process. The saved JSON data must be left untouched by this UI repair.

### Technical limits
Office documents are resolved by COM automation by exact native window handle; Office may not expose every window/instance through this interface. No generic title-to-file guessing occurs. File Explorer tabs/virtual folders and browser pages are not reliably restorable. Success in starting a file association means only that a Windows open request was sent, not that the app finished loading it.
