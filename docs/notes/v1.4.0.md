# WindowDeck 1.4.0 — release candidate (requires Windows testing)

## English

### Saved window sets
- In Update set, show a small floppy-disk icon beside every entry already saved in the set. Existing entries remain checked even if closed; new windows appear unchecked. The disk distinguishes set membership from the separate green check/red X for reopening readiness.
- Save any number of named collections of the windows currently open.
- All available windows are initially checked; use Select all, Deselect all or individual checkboxes.
- Reopen reliably identified local File Explorer folders and local Excel, Word, and PowerPoint documents without closing existing windows.
- Repeated opens skip resources detected as already open or already requested during the current session.
- Unsupported windows are retained as visible entries in saved sets but cannot be automatically reopened (e.g., browser tabs, unsaved Office documents, application dialogs, and unresolved Office instances).
- Rename, replace and delete saved sets. They are saved only in the Windows user profile under %LocalAppData%\WindowDeck\window-sets.json.
- Reopening is best effort: no guarantee of unchanged application internals, unsaved changes, monitor placement, tabs, or file availability. Partial results are reported.

### Close saved window set / Zamknij zestaw

- Close set asks for confirmation and sends normal window-close requests for **currently open, exactly matched documents and folders in the saved set**.
- The application itself prompts to save unsaved edits when necessary. Choosing Cancel keeps the window open. WindowDeck neither kills processes nor bypasses save prompts.
- Unresolved and program-only entries (including browsers whose tabs are not tracked) are **skipped** to avoid closing unrelated documents. The saved set stays intact and can be reopened.
- Show close request counts and skipped items inline in the manager; closing is not guaranteed merely because Windows accepted a request.

### Saved sets preview refresh
- Replace the former dense table with **collapsible groups per application** and clean, two-line document cards with no white grid or column headers.
- Show a compact path and tooltip for the full file location, native green check/red X for readiness, a contextual **Copy full path** option, and vertical scrolling. The theme follows WindowDeck's light/dark palette.

### Improved reopening of files and programs

- The saved-set manager opens to the left of WindowDeck and stays in front.
- Assign a specific local document to any saved window with Choose file / Wskaż plik, including .txt for Notepad and PDF documents for readers like Foxit.
- Reopen program-only entries such as Chrome or Firefox without claiming to recover tabs.
- Missing documents are reported by their saved full path; remaining items still reopen.
- For tab-capable PDF readers, opening each document in a separate window may improve WindowDeck's window-level grouping, but does not guarantee automatic file-path discovery.

### Window and settings polish

- Keep Settings OK and Cancel visible in a fixed footer while the settings options alone scroll, including on smaller displays.
- Apply the active light/dark theme to the native title bars of Saved window sets and Save current/Update set dialogs.
- Ensure Prepare presentation screen always opens above the WindowDeck flyout instead of behind it.

### Fixes
- Bounded event-triggered refresh of the window list during continuous window changes.
- Reinforced flyout Always on top after opening and window activation, subject to Windows Z-order constraints.
- Atomic refresh ordering of application headers and rows to address occasional misordered window groups.
- Settings > Maintenance: optional manual removal of stale WindowDeck taskbar-personalization entries from other executable locations, after exporting registry backups. Current instance and other apps' records are preserved.

This is not a released or Windows-verified build until accepted by the user.

## Polski

### Zapisane zestawy okien
- Przy aktualizacji zestawu mała ikona dyskietki oznacza każdą już zapisaną pozycję. Takie okna pozostają domyślnie zaznaczone, nawet gdy są zamknięte; nowe są odznaczone. Dyskietka oznacza przynależność do zestawu, a zielony haczyk lub czerwony X — możliwość przywrócenia.
- Zapis dowolnej liczby zestawów z własnymi nazwami.
- Domyślnie wszystkie okna zaznaczone; dostępne Zaznacz wszystkie, Odznacz wszystkie i osobny wybór każdego okna.
- Ponowne otwieranie rozpoznanych lokalnych folderów Eksploratora oraz dokumentów Excel, Word i PowerPoint bez zamykania aktualnie otwartych okien.
- Pomijanie rozpoznanych już otwartych plików lub żądań otwarcia wysłanych w bieżącej sesji.
- Okna nieobsługiwane (np. karty przeglądarki, niezapisane dokumenty, dialogi i okna programów bez wiarygodnej ścieżki) są zachowywane na liście zestawu, ale nie zostaną automatycznie otwarte.
- Zmiana nazwy, aktualizacja i usuwanie zestawów. Dane zapisane wyłącznie lokalnie w profilu Windows.
- Odtwarzanie działa w dostępnym zakresie: nie przywraca niezapisanych zmian, wewnętrznego stanu aplikacji, kart ani położenia na monitorach. Program pokazuje podsumowanie.

### Przywracanie konkretnych plików i programów

- Okno Zapisane zestawy okien otwiera się obok głównego panelu WindowDeck, po jego lewej stronie, i nie powinno być przez niego zasłaniane.
- Przy zapisie można wskazać konkretny plik dla dowolnego okna, np. plik .txt dla Notatnika lub PDF dla Foxit Readera.
- Przeglądarki i programy bez rozpoznanego dokumentu można uruchomić ponownie w trybie „tylko program”, bez przywracania kart.
- W razie braku pliku WindowDeck pokaże jego zapisaną ścieżkę i będzie otwierał pozostałe pozycje zestawu.
- W programach obsługujących karty można rozważyć ustawienie osobnego okna dla każdego dokumentu. Ułatwia to rozpoznawanie okien, ale nie gwarantuje automatycznego ustalenia ścieżki pliku.

### Poprawki
- Odświeżanie listy nieblokujące się podczas ciągłych zdarzeń okien.
- Wzmocnione utrzymywanie głównego panelu na wierzchu.
- Spójna kolejność grup i okien podczas przebudowy listy.
- Ręczne czyszczenie historycznych wpisów WindowDeck w personalizacji paska zadań z kopią zapasową.
