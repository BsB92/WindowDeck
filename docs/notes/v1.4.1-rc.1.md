# WindowDeck v1.4.1 RC1 — TEST BUILD / WERSJA TESTOWA

**This is a pre-release for testing, not the stable version.** It contains the unmerged changes from PR #52. The published stable version remains v1.4.0.

## What to test

- **Saved sets → Save current / Update set** should remain responsive while Office windows and OneDrive/SharePoint documents are being inspected. Document discovery uses a background STA worker.
- Saved-set file availability checks run in the background rather than blocking the WindowDeck interface.
- **Choose file** now supports pasting the full local file path (use Explorer → Copy as path), even when Excel has the workbook open.
- Existing sets should retain saved entries even if their windows are closed. Previously saved JSON should not change on cancel or scan timeout.

**Known limitations:** This is not an automatic SharePoint URL resolver. Use the locally synced file path, not a browser URL. Manually linked cloud files may not always be recognized as already open when restoring sets.
